- Добавлена корректная обработка adopted объектов расширения.

- Исключено ошибочное наследование части свойств из основной конфигурации там, где Конфигуратор печатает платформенные defaults.

### XML-derived overrides

- Реализован генератор project-specific override JSON из XML, а не из эталонного `Report.txt`.
- Через него собираются узкие owner-specific правила для стандартных реквизитов и похожих случаев.
- Для `orders` используется:
  - `generate_config_report/settings/generated/orders.xml-overrides.json`
- Формирование XML-derived overrides теперь можно включить прямо из основного `generate_config_report.py` через project config key `buildXmlOverrides`.
